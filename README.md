# Chat UI — Metawurks Internship Task 1

A functional chat interface built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## How to run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Features
- Real-time chat UI
- Mock AI responses with typing indicator
- Responsive design
- Error handling
